What this API does

VIN history

Ask if a chassis is in our archive, then retrieve listings, auctions, events, accidents, salvage, and photos. Five curated test VINs are free on your API key; real chassis use prepaid credits only on HTTP 200.

Live Feed Korea

Stream current Encar, Autowini, and KB inventory onto your own site. Same API key as history — enable live on your account first. Live calls do not spend VIN credits.

Credits & signup

Registration issues one production API key (zero credits). Test VINs need no top-up. Buy USDT credits in the client area for real retrieves — empty balance returns 402.

Billing rules

Check free → retrieve only on match

When credits are charged.

  1. 1

    Check Free

    GET /api/v1/vin/check/{vin} needs Authorization: Bearer vdi_…. No credit. Returns exists and country. HTTP 200 if we have it, 404 if not.

    If exists is false, stop. Nothing to retrieve, nothing billed.

  2. 2

    Retrieve 1 credit on 200

    GET /api/v1/vin/{vin} needs Bearer. A credit is charged only on HTTP 200 for real VINs. Five curated test VINs use this same URL for free — see the client area.

    404 not found · 429 rate limited · 402 no credits — none of these charge.

  3. 3

    Live No VIN credit

    /api/v1/live/* needs Bearer and live feed enabled on your account (403 LIVE_FEED_DISABLED otherwise). Live traffic is not metered as VIN credits.

Endpoints

One vdi_ API key for check, retrieve, test VINs, and live. Only a successful real-VIN retrieve spends a prepaid credit.

Car history

VIN archive

Check is free (Bearer required, no credit). Retrieve is authenticated; real VINs are metered, test VINs are free.

GET /api/v1/vin/check/{vin} Free

Use when Ask whether we have this VIN before you retrieve. Use it to avoid spending a credit on empty lookups.

Authenticated check. Requires Authorization: Bearer vdi_…. Never consumes a credit. HTTP 200 if we have the VIN; HTTP 404 if we do not.

Auth

Authorization: Bearer vdi_…

Parameters

  • Authorization headerBearer vdi_… (required)
  • vin path5–17 alphanumeric characters (A–Z, 0–9). Normalized to uppercase.

Status codes

  • 200VIN exists — success true, exists true, country slug
  • 404VIN not in database — success false, exists false, country null
  • 401Missing / invalid / expired token
  • 400INVALID_VIN — length or charset failed
Sample response 
{
  "success": true,
  "data": {
    "vin": "WDDUX8GB8JA397509",
    "exists": true,
    "country": "south_korea"
  }
}
Example request 
curl -H "Authorization: Bearer vdi_your_token" \
  https://getcarapi.com/api/v1/vin/check/WDDUX8GB8JA397509
GET /api/v1/vin/{vin} 1 credit

Use when After check returns exists: true. Returns the full archive record for that chassis. The five curated test VINs use this same URL — free on HTTP 200 (`meta.creditCharged: 0`).

Authenticated retrieve. One prepaid credit is charged only when the response is HTTP 200 for a real VIN. Curated test VINs are free (`meta.creditCharged: 0`). 404 / 402 / 429 do not charge.

FAQ

Precise answers

Do I need a token to check a VIN?

Yes. GET /api/v1/vin/check/{vin} requires Authorization: Bearer vdi_… but never uses a credit.

How do test VINs work?

Same URLs as real VINs: GET /api/v1/vin/check/{vin} and GET /api/v1/vin/{vin}. Five curated sandbox VINs retrieve for free (meta.creditCharged: 0). Pick them in the client area.

When is a credit used?

Only when GET /api/v1/vin/{vin} returns HTTP 200 for a real (non-test) VIN. 404, 402, and 429 do not bill.

Do live calls use VIN credits?

No. Live needs Bearer and live feed enabled on your account. It is not prepaid-credit metered.

How do I buy credits?

In the client area, submit a crypto purchase with your transaction hash. Credits are added after verification.

How do I mix Encar and Autowini?

provider=all (or combined). Short aliases like encar and *_live both work.

Where is the machine-readable spec?

OpenAPI — sign in to browse VIN and live routes.

How billing works
