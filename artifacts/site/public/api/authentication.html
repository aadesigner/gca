Bearer token

How authentication works

One API key per account from signup. Prefix is always vdi_. Full secret is shown once.

Header format

Authorization: Bearer vdi_your_token
  • Prefix must be vdi_
  • Never put the token in the query string or path
  • Lost or leaked? Request a replacement via support — rotation is admin-only
  • Real VIN retrieves need prepaid credits; test VINs and check are free
  • Live feed requires account enablement

Which routes need it?

FreeGET /api/v1/vin/check/{vin}Bearer · no credit
1 credit on 200GET /api/v1/vin/{vin}Bearer · same URL · test VINs free
Live accessGET /api/v1/live/*Bearer · enablement required

Rate limits

Caps apply to successful retrieves only

Live feed traffic is authenticated but outside these three counters.

DailySuccessful GET /vin/{vin} (HTTP 2xx) per UTC day

Per VINThrottle repeated retrieves of the same chassis in a month
Also required: prepaid credits

Retrieve needs available credits. Empty wallet → 402 INSUFFICIENT_CREDITS. Manage balance in the client area.

FAQ

Authentication

Same token for live and history?

Yes. One vdi_ API key covers check, retrieve, test VINs, and live. Only real-VIN retrieves spend credits.

Is there a separate test key?

No. One production key per account. Five curated test VINs are free on that key — no sandbox token.

Can I rotate my API key?

No — open a support ticket if you need a replacement. Only admins can revoke and issue a new secret.

What if the token leaks?

Open a support ticket in the client area. Only admins can revoke and issue a replacement key.

When is live feed available?

Live routes return 403 LIVE_FEED_DISABLED until enabled on your account. Request access from the client area or support.

Does 404 still require auth?

Yes. Missing VINs return 404 with a valid Bearer — no credit is consumed.

Auth error codes?

MISSING_TOKEN, INVALID_TOKEN, TOKEN_EXPIRED, CLIENT_DISABLED (401). ENDPOINT_NOT_ALLOWED (403) if the key’s allowed routes exclude the path.

How billing works

Ask first. Then retrieve.

See if this VIN is in the archive before a credit is used. You pay only when GET /api/v1/vin/{vin} returns HTTP 200 with the full record.

  • Free check — Bearer required, no credit
  • 5 test VINs — free retrieve on your API key
  • 1 credit — only on HTTP 200 for real VINs
  • Nothing billed — 404 not found or 429 rate limit
